# QA Learning Hub

Полнофункциональное веб-приложение для отслеживания обучения QA-тестировщиков в 10-лекционном курсе по основам фронтенда.

## Стек технологий

### Frontend
- React 18 + TypeScript
- Vite (сборщик)
- Tailwind CSS (стили)
- React Router 6 (маршрутизация)
- Axios (HTTP-клиент)

### Backend
- Node.js + Express
- SQLite3 (better-sqlite3)
- JWT (аутентификация)
- bcryptjs (хеширование паролей)

## Функции

### Аутентификация
- Вход через email + пароль
- JWT токены в localStorage
- Ролевая маршрутизация (тестировщик / ведущий)

### Кабинет тестировщика
- Профиль с аватаром и именем
- 4 метрики: завершено лекций, средняя оценка, рост навыков, недель осталось
- Список 10 лекций со статусами (заблокирована / активна / пройдена)
- Прогресс-бары показывают оценки за тесты
- Деблокировка следующей лекции только после прохождения текущей (≥60%)

### Система тестирования
- Каждая лекция: 5–7 вопросов (один правильный ответ)
- Мгновенная обратная связь с объяснением
- Прогресс-бар "Вопрос N из M"
- По завершении: показывается оценка, сохраняется в БД
- Деблокировка следующей лекции при оценке ≥60%

### Dashboard ведущего
- Таблица команды: имя, прогресс, средняя оценка, рост навыков, завершено лекций
- Вкладка "До/После": горизонтальные полоски сравнения базовых и текущих оценок по 5 навыкам
  - HTML структура, Чтение CSS, DevTools, Ошибки консоли, Качество отчётов
- Лента активности: 10 последних действий (кто прошёл что, когда)

### Отслеживание "До/После"
- При первом входе каждый тестировщик заполняет начальную анкету (5 навыков, оценка 1–5)
- Базовые оценки сохраняются и не перезаписываются
- После лекции 10: тестировщик заполняет итоговую анкету
- Dashboard ведущего показывает дельту для каждого навыка на человека и среднее по команде

```bash

```

### 2. Инициализация БД

```bash

```

### 3. Запуск

```bash
npm run dev
```

Сервер: http://localhost:5000
Фронтенд: http://localhost:5173

Это создаст `server/db/learning_hub.db` с полным набором тестовых данных:
- 5 пользователей (1 lead + 4 testers)
- 10 лекций по QA тестированию фронтенда
- 50 вопросов (5 на лекцию)
- Реалистичный прогресс тестировщиков
- Начальные анкеты навыков

## Данные БД

### Схема таблиц
- `users` — пользователи (lead/tester)
- `lectures` — 10 лекций с названиями и областями навыков
- `questions` — вопросы для тестов (5–7 на лекцию)
- `test_results` — результаты прохождения тестов
- `baseline_survey` — начальные оценки навыков (1–5)
- `final_survey` — итоговые оценки после курса
- `activity_log` — лента активности

## API Endpoints

### Auth
- `POST /api/auth/login` — вход в систему

### Tester Cabinet
- `GET /api/tester/profile` — профиль пользователя
- `GET /api/tester/metrics` — метрики (завершено, средняя оценка, рост, недель)
- `GET /api/tester/lectures` — список лекций со статусами
- `POST /api/tester/baseline-survey` — отправка начальной анкеты
- `POST /api/tester/final-survey` — отправка итоговой анкеты

### Quiz
- `GET /api/lectures/:id/questions` — вопросы лекции
- `POST /api/lectures/:id/submit-test` — отправка ответов
- `GET /api/lectures/:id/question/:qid/explanation` — объяснение вопроса

### Lead Dashboard
- `GET /api/lead/team` — данные команды
- `GET /api/lead/before-after` — сравнение "до/после" по навыкам
- `GET /api/lead/activity` — лента активности

## Примечания

- БД хранится локально в `server/db/learning_hub.db`
- Все пароли хешируются bcryptjs
- JWT токены хранятся в localStorage
- Лекции можно проходить снова (результат будет перезаписан)
- Backend автоматически отслеживает активность пользователей
